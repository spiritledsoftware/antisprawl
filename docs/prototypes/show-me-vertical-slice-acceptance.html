What issue #9 is trying to prove

Before building Antisprawl, we need a small set of examples that tells us whether the first end-to-end version is useful and honest.

The core test is simple: add four functions, then demand exactly two Findings—not zero, not four.

Then try to break it

The signal alone is not enough. The slice also fails if it leaves stale data behind or hides what went wrong.

  • Rewrite the copied function Its old Finding disappears; the unchanged near-miss still appears in manual output.
  • Interrupt indexing after one completed provider batch The Index stays readable and resumes only the missing content hashes.
  • Make listEligibleJobs unparsable Its stale Finding is excluded; unaffected results remain; Coverage says degraded.
  • Fail Codex authentication, transport, or response validation A typed diagnostic appears and Structural-only analysis runs without stale Semantic evidence.
  • Fail sqlite-vec after recording a native semantic result Application exact search returns the same candidates and Findings over the same vector BLOBs.
  • Give invalid configuration or an unsafe Index operation The command fails clearly and leaves the existing Index unchanged.

The actual decision

This matrix is a gate for starting the build sequence. It is not a claim that four functions calibrate the finished detector.

Accept the vertical slice

  • Exactly two correct Findings
  • No stale or trivial Findings
  • Safe interruption and resume
  • Honest Coverage, exit status, and fallback
  • Versioned JSON without source, vectors, or credentials
  • At least one embedding dimension passes unchanged expectations

Reject the vertical slice

  • Either positive is missed
  • Either hard negative is reported
  • Affected stale work survives an edit or parse failure
  • Resume repeats completed provider work or corrupts the Index
  • A fallback changes results without saying so
  • The protocol leaks data or hides failure

Not decided here: exact thresholds, candidate counts, final calibration, implementation filenames, or whether a compact filter rewrite is structurally close enough. Those need broader evidence.

If the expected “two Findings, two quiet” result and the failure behavior above match what you mean by a useful first slice, issue #9 is ready to close. If not, the disagreement is now one concrete example rather than an abstract test plan.
